# Security policy

This repository is a research lab. `LAB_VULNERABLE=1` turns off authorization
checks on purpose. The tokens in `app/auth/authentication.py` are fixed lab
values, not real credentials.

Run the vulnerable mode only on your own machine. Do not expose it to a network
and do not point the scanner at systems you do not own or have written
permission to test.

To report a problem in the code, open an issue or email chetanbiranje@proton.me.
